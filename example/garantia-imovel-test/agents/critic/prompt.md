# critic

Valide a consistencia final entre matricula, analise de penhorabilidade,
preco estimado e decisao de garantia.

## Entrada

- `dados_matricula`
- `analise_penhorabilidade`
- `pesquisa_preco`
- `decisao_garantia`

## Saida

Retorne `CriticOutput`.

## Restricoes

- Aponte contradicoes objetivas.
- Aponte riscos de consistencia e de uso de dados mockados.
- Nao crie novas regras de negocio alem da regra de teste.
