# Platform Project Specification

## Purpose

This repository provides a reusable AI-native platform for generating multi-agent systems.

The platform is responsible for:

* scaffolding
* repository topology
* orchestration conventions
* evaluation conventions
* observability conventions
* project generation standards

This repository is NOT a business implementation.

Business projects must be generated separately using this platform.

---

# Platform Responsibilities

The platform owns:

* scaffolding logic
* reusable templates
* project conventions
* architecture standards
* generation rules
* workflow architect capabilities

The Workflow Architect is a design-time platform capability for inferred architecture. It helps coding agents choose patterns and propose agents before scaffold execution. It is not a runtime execution engine.

The platform does NOT own:

* business prompts
* domain logic
* company-specific workflows
* project-specific agents

# templates/

Contains reusable project templates.

Examples:

* agent templates

* evaluation templates

---

# examples/

Contains reference implementations built using the platform.

Examples:

* credit analysis systems
* research assistants
* compliance workflows

Examples validate platform capabilities.

Examples are not part of the platform core.

# Runtime Architecture

Generated projects should support:

* LangGraph orchestration
* LangChain runtime abstractions
* Pydantic contracts
* Langfuse observability
* RAGAS evaluation
* DSPy optimization

---

# Evaluation Architecture

Evaluation must remain isolated from runtime execution.

Preferred:

```text
eval/
```

Evaluation should support:

* Golden Sets
* RAGAS
* regression testing
* LLM-as-a-Judge

---

# Tooling Architecture

External integrations should be implemented as tools.

Preferred:

```text
agents/<agent-name>/tools/
```

Shared clients should only be used for:

* authentication
* cross-agent integrations
* reusable infrastructure clients

---

# Platform Philosophy

This platform is optimized for:

* coding agents
* semantic locality
* low navigation cost
* explicit contracts
* deterministic repository generation

The platform favors:

* scaffolding over manual setup
* convention over configuration
* AI-native repository structures
* low cognitive overhead
